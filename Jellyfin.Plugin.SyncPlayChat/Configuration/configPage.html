🗨️ SyncplayChat Settings

Shows a real-time chat panel on the right side of the video player when you are in a Syncplay session.
Number of past messages to load when you join a Syncplay room (10–200).

📌 Setup Required

This plugin requires the File Transformation plugin to inject the chat overlay into the Jellyfin Web client.

Add this repository in Dashboard → Plugins → Repositories:
https://www.iamparadox.dev/jellyfin/plugins/manifest.json
